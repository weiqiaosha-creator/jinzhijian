瑾之笺·稳定版

多格式拖入 · 模板筛选 · 推草稿 / 定时群发（独立版权 · 稳定构建）

① 拖入文件

把 .md / .docx / .pptx 拖到这里，或点击选择
（.doc 请先另存为 .docx；支持 GIF 动态图）

    ② 设置

    留空=仅推草稿，由你在后台发布

    凭证仅存本机 localStorage，经本地服务 server.js 调用微信接口；不写入任何代码或上传第三方。需把本机出口 IP 加入公众号 IP 白名单。

    ③ 免费图库（点击展开，按关键词搜图）

    动态图请选 GIPHY / Tenor；插入时复制图片地址，放进你的 Markdown 里（推送模式会自动上传微信图床保留动画）。各站许可以官网声明为准。

    ④ 实时预览（微信内效果）

    预览为微信内联样式渲染效果。复制 HTML 后到公众号后台 Ctrl+V 粘贴即可；或填好凭证点"推送"经 API 入草稿。个人号定时发送请用浏览器插件（已内置个人号自动发表）。
